ASSUMPTIONS & DECISIONS
  • No design system was attached (the linked one is empty), so this system is built from the brief: felt green, rail-brown, warm gold, cream.
  • Playfair Display for signage + every amount (lining, tabular figures); Manrope for UI. Both free on Google Fonts.
  • Phone canvas 390×844. Primary tap targets 52–58px; nothing interactive under 44px. Thumb zone owns all betting controls.
  • Light mode = “same casino in daylight”: ivory room, lighter felt, warm wood rail. Felt/rail and seat name-plates keep cream-on-dark so the table reads the same in both modes.
  • Rupee notes use colour, proportion (≈2.17:1), big numeral, ₹ and an abstract sunburst only — no portraits, emblem, RBI text, serials or watermark window.
  • Seat avatars are initials on a stable per-player colour; photos can drop in later.
  • Tall screens (lobby, template editor, report) are shown fully scrolled.

FLIGHTS & POOL
  • Bet placed: notes fly from seat → pool on a quadratic arc (control point 40% toward centre, lifted 60px). 420ms, cubic-bezier(.3,.7,.2,1). Note scales 1 → .8 and rotates −20° → +4°. Multiple notes stagger 60ms.
  • Pool: on land, stack adds the note at a random rotation (±12°) and pulses scale 1.08 over 180ms; total counts up over 300ms (tabular figures so width never jitters).
  • Payout: pool stack bursts into notes that fly to the winner seat(s), 600ms, stagger 40ms; team split fans to each seat. Winner screen: gold rays rotate slowly (20s/rev), amount counts up 800ms.
  • Undo: the bet flies back out of the pool to the seat, 320ms, feed row strikes through left→right 200ms.
 
GESTURES · HAPTICS · SOUND
  • Tap note in wallet → adds 1 to built stack. Haptic: light impact. Sound: paper flick.
  • Tap built stack → removes the top note (flies back to its wallet cell, 180ms). Haptic: light.
  • Drag / swipe stack up (≥ 80px or velocity > 600px/s) → place bet. Stack follows finger 1:1, pool ring glows when inside drop radius. Release outside → springs back. Haptic: medium on drop, success pattern on confirm. Sound: soft “thup”, chip clack in chip theme.
  • Long-press feed row (host) 500ms with a gold ring filling → undo menu. Haptic: heavy.
  • My turn starts: seat + tray glow (2.4s breathe), haptic double-tap, a short bell. Turn timer is informational only.
  • Win: success haptic + coin cascade sound.

ANATOMY
  • Top bar: feed (unread count) · game + live/connection status · host controls (♛, host only).
  • Ticker: latest feed entry; tap to open the feed drawer.
  • Seats: 52px avatar, dark name-plate with wallet, status line (BLIND/SEEN · last bet). Active = gold ring + breathing glow + timer chip. Packed = 40% opacity.

RULES
  • Team split = floor(pot ÷ winners); the ₹ remainder goes to one winner chosen at random — shown with a dice tag so nobody argues.
  • Borrow requests only move money after the lender taps “Lend”. Loans stay open until either side marks repaid.
  • Cash out removes a player and freezes their net for the report.
